# Multi-Salon Web App - Frontend

This is the frontend client for the application, built using React.js. It provides a modern, responsive user interface and connects to the backend API to manage data dynamically for Customers, Staff members, and Super Admins.

## 🚀 Tech Stack
- **React.js** (Frontend Library)
- **React Router Dom** (Navigation)
- **Axios** (API Integration)
- **Tailwind CSS** (Styling)
- **Vite** (Build Tool)

## 🛠️ Getting Started

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed (v16 or higher recommended).

### 2. Installation
Navigate to the frontend folder and install the necessary dependencies:
```bash
npm install
```

### 3. Running the App
Start the development server:
```bash
npm start
```
This will start the Vite development server. Open your browser and navigate to the displayed local URL (typically `http://localhost:5173`).
