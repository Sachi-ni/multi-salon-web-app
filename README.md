# Multi-salon Web App (MERN scaffold)

This repository contains a minimal MERN scaffold: `backend` (Express + Mongoose) and `frontend` (Vite + React).

Quick commands

Windows (cmd):

```bat
cd backend
npm install
copy .env.example .env
npm run dev

:: in a separate terminal
cd frontend
npm install
npm run dev
```

Notes
- The backend expects `MONGO_URI` and `JWT_SECRET` in `.env`.
- Adjust ports if necessary.
